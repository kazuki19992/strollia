# GPX Import Achievement Alert Design

## 1. Purpose

GPXファイルをインポートする前に、インポート由来のデータでは一部の実績だけが判定対象になることをユーザーへ明示する。

現在の実績評価では、GPXインポート後に総移動距離と記録日数のような保存済みログ全体から再評価できる実績は判定される。一方で、訪問地域など実際の記録中に確認・保存する情報に依存する実績は、GPXインポートでは更新されない。

## 2. Scope

今回実装する範囲は以下とする。

- 設定画面の「GPXファイルのインポート」を押した直後にAlertを表示する
- AlertはOS標準のファイル選択画面を開く前に表示する
- Alertのタイトルと本文は承認済み文面を使う
- 既存のGPX読み込み、パース、保存、完了/失敗Alertの挙動は変えない

今回実装しない範囲は以下とする。

- 実績判定ロジックの変更
- GPXインポートで訪問地域を記録する処理の追加
- Alertにキャンセル/続行の分岐を追加すること
- 設定画面の説明文変更

## 3. User-Facing Copy

タイトル:

```text
GPXインポートと実績について
```

本文:

```text
GPXインポートでは、総移動距離や記録日数など一部の実績だけが判定対象になります。訪問した地域など、実際の記録中に確認する実績には反映されません。
```

## 4. Flow

`src/app/App.tsx` の `importGpx()` は既存どおりGPXインポートフローの所有者である。

新しいAlertは以下の順で表示する。

1. インポートボタンを押す
2. 多重実行中であれば何もしない
3. 選択ハプティクスを実行する
4. インポート中状態へ切り替える
5. 実績に関する注意Alertを表示する
6. `pickAndReadGpxFile()` でファイル選択を開始する
7. 以降は既存フローどおり、キャンセル時は何もせず、成功/空/失敗時は既存Alertを表示する

React Native の `Alert.alert(title, message)` は追加ボタンを指定しない場合、標準の閉じる操作だけを表示する。今回は注意喚起が目的であり、インポート可否の確認ダイアログにはしない。

## 5. Testing

`App.tsx` のGPXインポートフローを対象に、以下を確認する。

- GPXファイル選択サービスを呼ぶ前に、実績注意Alertが表示される
- ユーザーがファイル選択をキャンセルした場合、既存どおり追加の完了/失敗Alertを出さない
- 既存のインポート中ガードは維持される

既存の完了Alert、空データAlert、失敗Alertの文面は変更しない。
