# チュートリアル エリア説明ページ設計

## 目的

初回起動チュートリアルに、Strollia で「エリア」と呼ぶ地図表示を説明するページを追加する。ユーザーが、歩いた場所が地図上へ蓄積されていく体験を理解してから実績の説明へ進めるようにする。

## 画面構成

既存の「画面下の項目」の次、「実績を集める」の前に新しいページを追加する。ページ追加後のチュートリアルは全6ページとし、順序は次のとおりとする。

1. Strolliaへようこそ
2. 画面下の項目
3. エリアを広げよう
4. 実績を集める
5. さいごに
6. 位置情報を確認してはじめる

## 表示内容

タイトルは次の文言とする。

> エリアを広げよう

本文は読みやすさを保つため、次の2段落に分けて表示する。

> 地図上で薄く色が塗られているマスを、Strolliaでは「エリア」と呼びます。

> 歩いた場所がエリアとして記録され、地図に少しずつ広がっていきます。いろいろな道を歩いて、自分だけの地図を育てていきましょう。

タイトルと本文の間に `assets/tutorial/area-instruction.png` を表示する。アクセシビリティラベルは `地図上のエリアの説明` とする。

## 画像表示

既存の「画面下の項目」ページと同じ画像枠、横余白、`resizeMode="contain"` を使用する。画像は枠の横幅を超えないよう縮小し、切り抜きや引き伸ばしを行わない。

現在の実装は既存画像固有のアスペクト比を定数としているため、画像ごとに `Image.resolveAssetSource` から元の幅と高さを取得し、固有のアスペクト比で表示サイズを計算する。画像情報を取得できない場合は、既存画像のアスペクト比を安全なフォールバックとして使用する。

画像枠の幅が未計測の初期描画では表示幅を0として扱い、レイアウト計測後に正しいサイズで描画する。ステップ切り替え時のダイアログリサイズアニメーションは既存動作を維持する。

## 実装範囲

- `FirstLaunchTutorialDialog` のステップ定義へエリア説明ページを追加する。
- チュートリアル画像の表示サイズ計算を、画像ごとのアスペクト比に対応させる。
- ページ数と順序の変更に合わせてコンポーネントテストを更新する。
- 新画像が枠内に収まり、固有のアスペクト比を維持することをテストする。
- `docs/mvp.md` のチュートリアル説明へエリア案内を追記する。

新しい画面専用コンポーネントは追加せず、既存のチュートリアルステップと画像表示の仕組みを拡張する。

## テスト方針

`FirstLaunchTutorialDialog` のテストで次を確認する。

- チュートリアルが全6ページとして表示される。
- 「画面下の項目」の次に「エリアを広げよう」が表示される。
- 承認済みの本文が2段落として個別に表示される。
- エリア画像とアクセシビリティラベルが表示される。
- 既存画像とエリア画像が、それぞれの元画像に対応するアスペクト比で枠内へ収まる。
- 最終ページの完了処理と再表示時の先頭ページ復帰が従来どおり動作する。

あわせて型チェック、関連テスト、`git diff --check` を実行する。
