# 速度メーター連続円弧デザイン

## 目的

マップ下部ダッシュボードのスピードメーターは、現在の速度をデジタル数値とアナログリングで表示している。

現状のアナログリングは短い縦棒を円周上に並べる方式だが、速度変化に対して表示が細切れに見える。これを、12時方向を0km/hとして時計回りに伸びる連続円弧へ変更し、速度帯ごとの現在速度をより自然に読める表示へ改善する。

## 表示仕様

速度リングは、停止時を除き、現在の速度帯に応じた色と上限速度を使って進捗を計算する。

| 速度帯 | 速度範囲 | 円弧色 | 完全円になる速度 |
| --- | --- | --- | --- |
| 停止 | 1km/h未満 | テーマカラーを明るくした色 | 円弧なし |
| 低速 | 1km/h以上30km/h未満 | 明るい青緑 | 30km/h |
| 車両 | 30km/h以上150km/h未満 | オレンジ | 150km/h |
| 高速 | 150km/h以上 | ピンク | 400km/h |

円弧の進捗は `現在速度 / 速度帯ごとの完全円速度` で計算し、0〜100%に丸める。

例:

- 15km/h は低速表示で `15 / 30 = 50%`
- 30km/h は車両表示へ切り替わり `30 / 150 = 20%`
- 100km/h は車両表示で `100 / 150 = 66.7%`
- 150km/h は高速表示へ切り替わり `150 / 400 = 37.5%`
- 400km/h以上は高速表示の完全円

速度帯の境界は、GPS保存品質判定と速度メーターで共有している `classifyMovementSpeed`、`VEHICLE_SPEED_MIN_KMH`、`FAST_SPEED_MIN_KMH` を引き続き使う。

## 実装方針

`src/app/components/MapBottomDashboard.tsx` の `SpeedDial` を、短い縦棒を複数描画する方式から `react-native-svg` の円ストローク方式へ変更する。

具体的には、速度リングの土台は既存の黒いベースリングを維持し、その上にSVGの `Circle` を重ねる。`strokeDasharray` と `strokeDashoffset` で表示する円弧長を制御し、`rotation="-90"` 相当の指定で12時方向から開始する。

円弧は `strokeLinecap="round"` とし、画像例のように先端が丸い連続リングにする。進捗が0%の場合は円弧を表示しない。進捗が100%の場合は完全円として表示する。

円弧の寸法、線幅、中心座標、半径、円周長、dash offsetの計算は、テストしやすい純粋関数または定数として分離する。

## テスト方針

見た目そのものはスナップショットに頼らず、描画を支える計算ロジックを中心に検証する。

- 速度帯境界:
  - 29.9km/h は低速色でほぼ完全円
  - 30km/h は車両色で20%
  - 150km/h は高速色で37.5%
  - 400km/h以上は高速色で100%
- SVG円弧計算:
  - 0% は円弧長0
  - 50% は円周の半分
  - 100% は完全円
  - 範囲外の進捗は0〜100%に丸める
- コンポーネント描画:
  - 速度計、距離情報、地名、ボタン類が従来どおり描画される

## 非対象

今回の変更では、速度算出ロジック、GPS品質判定、保存済みルート線の描画品質は変更しない。

また、速度帯の閾値そのものは既に共有定数として `30km/h` と `150km/h` に更新済みのため、今回の主対象はアナログメーターの描画方式と進捗上限の扱いに限定する。
