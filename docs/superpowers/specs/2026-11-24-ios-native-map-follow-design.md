# iOS 標準アイコンの現在地追従

本番の STROLLIA-J では、地図の位置イベントを受けて現在地の状態を更新する際に React の更新深度エラーが発生した。iOS の標準アイコンでは Apple Maps の追従とアプリのカメラ指示が重複している。エラーとの因果関係は未確定。

iOS の標準アイコンでは、地図の準備と現在地取得が揃った時点で一度だけ通常縮尺に合わせ、以降の自動追従を Apple Maps に任せる。Apple Maps の追従は地図の中心だけを動かすため、アプリで初回の縮尺を設定する。位置と速度は引き続き更新し、地図が返す表示範囲と GPS 記録の更新通知で訪問済みグリッドを同期する。Android の標準アイコン、カスタムアイコン、現在地ボタン、地図復帰時の中央寄せは既存経路を使う。

自動テストでプラットフォーム別のカメラ指示と座標・速度の更新を確認する。iOS 実機では初回の縮尺、移動中の追従、ドラッグと現在地ボタン、訪問済みグリッドの反映、バックグラウンドからの復帰を確認する。
