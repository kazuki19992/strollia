# 実装Todo

## 1. 方針

Strollia は、まず小さなMVPを完成させる。

初期実装では、高度なインポート/エクスポートや写真ジオタグの時刻連動などの難易度が高い機能は後回しにし、GPSログを安全にローカル保存してマップ上で確認できる状態を最優先する。
