# パック詳細: 複数地点スポットの地点リストを展開/格納する 設計書

## 目的

パック詳細画面では、複数地点スポット(日本三景の松島など)の下に地点行が常に並んでいる。今は1スポットあたり3〜4地点で済んでいるが、地点が増えると一覧が長くなり見づらい。スポットの行をタップして地点リストを展開/格納できるようにし、一覧をすっきりさせる。

## 決定事項(ユーザー決定)

- **開閉の操作**: 複数地点スポットの行をタップすると、地点リストを開閉し、同時に埋め込み地図をそのスポット全体へズームする。
- **初期状態**: パック詳細を開いたとき、地点リストはすべて閉じておく。

## 挙動

### 複数地点スポットの行

- タップすると、そのスポットの地点リストを開閉する(閉じていれば開き、開いていれば閉じる)。あわせて埋め込み地図をそのスポット全体へズームする。
  - ズームは開くときも閉じるときも行う。行のタップで毎回同じことが起きるほうが分かりやすいため。
- コンプリート済みのスポットも同じ挙動にする。これまでのスポット行のタップ(スポット到達日の日別記録を開く)はやめる。日別記録は、開いた中の各地点の行から開ける。
- 行の右端には、閉じているときは下向き(`chevron-down`)、開いているときは上向き(`chevron-up`)の矢印を出す。これまでの右向きの矢印(画面遷移の印)は出さない。
- 進捗(`到達地点数/地点数`、コンプリート後は「コンプリート日: 」)、スタンプ、番号バッジはこれまでどおり。
- スクリーンリーダーには、開閉状態(`accessibilityState.expanded`)を伝える。読み上げラベルは `松島の地点を開く` / `松島の地点を閉じる` とする。

### 地点の行

- 開いているときだけ、これまでどおりスポット行の下に字下げして並べる。タップの挙動(到達済みならその日の記録、未到達なら地図をその地点へズーム)も変えない。

### 円1つのスポット

- 変えない。地点リストがないため開閉もしない。

### 開閉状態の保持

- 開閉状態は画面の中だけで持ち、保存しない。パック詳細を開き直すと、すべて閉じた状態に戻る。
- 日別記録へ進んでから戻ってきたときは、画面が残っているので開閉状態もそのまま残る。

## 実装方針

- **開閉状態**: `LandmarkPackScreen` の中で、開いているスポットIDの集合を state として持つ。画面内だけのUI状態なので `AppStateProvider` には載せない。
- **矢印**: 汎用の `AppListItem` に、開閉できる行のための `expanded?: boolean` を追加する(私の判断)。
  - 指定したときは、右端に `expanded` に応じて `chevron-up` / `chevron-down` を出し、`accessibilityState.expanded` を付ける。`showChevron` の右向き矢印は出さない。
  - 指定しないときは、これまでどおり。
- **アニメーション**: 開閉のアニメーションは付けない(私の判断)。まず素直に出し入れし、使ってみて必要なら後から足す。
- 文言(`の地点を開く` / `の地点を閉じる`)は `src/ui/appText.ts` に置く。

## テスト

- `AppListItem`: `expanded` を指定すると上下の矢印と `accessibilityState.expanded` が付き、右向きの矢印は出ない。指定しないときは変わらない。
- `LandmarkPackScreen`:
  - 初期状態では地点の行が出ていない。
  - スポット行をタップすると地点の行が出て、地図がスポット全体へズームする。もう一度タップすると地点の行が消え、地図はまたズームする。
  - コンプリート済みのスポット行をタップしても日別記録は開かず、開閉する。地点の行からは日別記録を開ける。
  - 円1つのスポットはこれまでどおり。
