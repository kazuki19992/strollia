# MVP仕様

## 1. 目的

MVPでは、Strollia の核となる「GPSログを記録し、ローカルに保存し、日別にマップで見返し、GPXとして取り出す」体験を完成させる。

## 2. MVPの範囲

MVPで提供する機能は以下とする。

- 手動開始・手動停止によるGPS記録
- SQLiteへのローカル保存
- 日別ログ一覧
- 日別マップ表示
- GPXエクスポート

## 3. 記録方式

初期実装では、常時自動記録ではなく、手動の開始・停止方式とする。

理由は以下である。

- OSごとのバックグラウンド権限制御を後回しにできる
- バッテリー消費を制御しやすい
- 実装と検証がシンプルになる
- GPSログ保存とマップ表示という中核機能に集中できる

## 4. 画面構成

MVPの画面は以下を想定する。

- ホーム画面
- 記録画面
- 日別ログ画面
- マップ画面
- エクスポート画面

初期実装では画面数を統合してもよい。たとえば、ホーム画面に記録操作、日付選択、マップ表示をまとめてもよい。

## 5. 成功条件

MVP完了条件は以下とする。

- アプリを起動できる
- 位置情報権限を許可できる
- 記録開始後、GPSポイントがSQLiteに保存される
- 記録停止できる
- 保存済みの日別ログを確認できる
- 選択日のルートがマップ上に線で表示される
- 選択日のログをGPXとして共有できる

## 6. MVPの非対象

以下はMVPには含めない。

- 常時バックグラウンド記録
- from-to のA/B点範囲指定
- KML対応
- インポート
- 写真ジオタグ表示
- 全履歴マップの高度な描画最適化

## 7. 技術候補

- アプリ: Expo + React Native + TypeScript
- 位置情報: `expo-location`
- DB: `expo-sqlite`
- マップ: `react-native-maps`
- ファイル出力: `expo-file-system`
- 共有: `expo-sharing`
