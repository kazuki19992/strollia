# iOS 標準アイコンの現在地追従 実装計画

**目的**　iOS の標準アイコンで、位置イベントごとのアプリ側カメラ指示を省く。

**設計**　[承認済みの設計](../specs/2026-11-24-ios-native-map-follow-design.md)

- [x] `useMapFollowState.test.tsx` に iOS と Android で標準アイコンの位置更新を検証するテストを追加する。両 OS で座標と速度が更新され、Android でのみカメラ指示が出ることを検証する。iOS は地図の準備後に初回の縮尺合わせを行い、その後はカメラ指示を出さないことも検証する。変更前は iOS の期待値で失敗することを確認する。
- [x] `useMapFollowState.ts` の標準アイコンの位置イベント内のカメラ指示を iOS 以外に限定する。iOS の初回の縮尺合わせは準備完了後の effect で一度だけ行い、`docs/map-rendering.md` の追従・グリッド同期の説明を更新する。
- [x] 対象テストを再実行し、型チェック、全テスト、lint、差分を確認してコミットする。
- [ ] iOS 実機で初回の縮尺、地図の追従、訪問済みグリッド、バックグラウンドからの復帰を確認する。
