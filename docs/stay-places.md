# 滞在場所の仕様とリリース確認

## 1. 挙動

滞在場所は名称、固定Twemojiアイコン、中心座標、共有時の非表示半径を持つ端末内設定である。無料版とPlus解約中は作成順で最初の1件だけを有効にし、Plus有効時はすべてを有効にする。解約しても登録済みの行は削除・更新せず、再契約時に全件を自動的に有効へ戻す。

リアルタイムの端末GPS記録だけは、有効な滞在場所の中心から50m以内の同じ場所を3点連続で観測した時点で、3点目以降の有効座標を中心へ吸着する。吸着中は50m外の点を3点連続で観測した3点目から生座標へ戻す。境界の50mは範囲内として扱う。入場・退出の連続観測状態は端末内SQLiteへ保存し、前景・背景の切替およびJSプロセス再生成後も引き継ぐ。バックグラウンド配信が1点ずつの場合も3点目から吸着する。GPXインポートと既存ログの再表示では吸着判定を行わず、過去ログを再計算しない。

生座標は常に`location_points.latitude` / `longitude`に保存する。距離、Visited Grid、通常のアプリ内ルート地図には保存済みの有効座標を使い、旧ログや片方だけの有効座標は生座標へフォールバックする。GPXエクスポートは常に生座標を出力し、GPXインポートは生座標をそのまま有効座標として保存する。

地図画面には、現在有効な滞在場所だけをTwemoji入りの四角い吹き出しで表示する。吹き出しをタップすると、アイコン、太字の場所名、グレーの非表示範囲を既存のスワイプ閉じ対応ダイアログに表示する。滞在場所の読込中または読込失敗時はマーカーを表示しない。

共有用の地図だけは、有効な滞在場所の非表示半径内の点と、その半径を横切る線分を除外する。対象は日別共有画像、日別GIF（プレビューを含む）、月次レポートである。除外点・線分の前後は別Polylineにし、1本の線でつながない。通常のアプリ内地図、SQLite、GPXには非表示範囲を適用しない。滞在場所を読み込めない場合、GPS記録は生座標のまま継続する一方、共有は生ルートへフォールバックせず、ユーザーにエラーを表示して開始しない。

固定アイコンはビルド時に固定したEmojibaseデータから生成し、Twemoji PNGをアプリに同梱する。Twemoji graphicsのCC-BY 4.0帰属表記は設定のOSSライセンス画面で確認できる。

## 編集画面

アイコンと共有時の非表示範囲は、アプリカラー設定と同じボトムシート型ドロップダウンで選択する。アイコンのトリガー・選択肢にはOS標準の絵文字フォントではなく、同梱Twemoji PNGを表示する。固定14件の選択肢は場所の用途名を表示し、将来の検索可能な絵文字ピッカーへ置き換えられるが、保存値は引き続きUnicode fully-qualified hexcodeとする。

選択肢が長い場合、ボトムシートの上端は画面上側のセーフエリアから16px下を上限とし、候補一覧だけを縦スクロールする。シート外側のタップで閉じられる。

非表示範囲の未設定値は「共有画像に含める」と表示する。範囲を選択すると中心位置選択マップに半透明の円を表示し、この円内のルートが共有画像・GIF・月次レポートから隠れることを説明する。通常の地図とGPXには影響しない。

## 2. iOS / Android 実機リリースチェック

各OSで新規のテスト用滞在場所を1件作り、中心と非表示半径を確認する。実機の確認結果はリリースPRへ記録する。

- [ ] 中心から50m以内で同じ場所を3点連続記録し、3点目から通常地図のルート・距離・エリアが中心座標を使うことを確認する。
- [ ] 中心から50m外を3点連続記録し、3点目から生座標へ戻ることを確認する。境界50mは範囲内として扱われることも確認する。
- [ ] 候補2点後にバックグラウンド移行またはJSプロセス再生成相当を挟み、次の1点で吸着することを確認する。
- [ ] 吸着後に画面を消灯しても、バックグラウンド記録で吸着状態を維持することを確認する。
- [ ] Plus有効時に2件以上を登録し、解約後は最初に作成した1件だけが有効表示・吸着・共有範囲の対象になることを確認する。再契約後は、削除せず残った全件が有効に戻ることを確認する。
- [ ] GPXをエクスポートし、吸着済みの有効座標ではなく元の生座標が`trkpt`へ出力されることを確認する。GPXを再インポートしても、現在の滞在場所へ吸着しないことを確認する。
- [ ] 通常のアプリ内地図は有効座標を表示し、共有時の非表示半径で消えないことを確認する。
- [ ] 日別共有画像、日別GIF（プレビューを含む）、月次レポートの各地図で、非表示区間の前後がつながらず、範囲内の点が露出しないことを目視確認する。
- [ ] 設定のOSSライセンス画面でTwemoji graphicsのCC-BY 4.0帰属表記を確認する。
