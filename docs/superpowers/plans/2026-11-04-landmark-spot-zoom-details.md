# パック詳細の地図: 拡大時のスポット名・解放条件・到達エリア表示 計画

ユーザーとチャットで合意した内容を実装する計画。小さめの変更のため設計書は作らず、合意内容をこの計画の冒頭に記す。

## 合意した仕様

パック詳細画面(`/achievements/[packId]`)の埋め込み地図 `LandmarkPackMapPreview` に、以下を追加する。

1. **スポット名**: 番号バッジ(①など)のすぐ上に表示する
2. **解放条件**: 番号バッジのすぐ下に表示する
   - `dwellSeconds` が 60分未満: `n分以上滞在で解放`(例: 180秒 → `3分以上滞在で解放`)
   - 60分以上: `h時間mm分以上滞在で解放`(例: 3600秒 → `1時間00分以上滞在で解放`、5400秒 → `1時間30分以上滞在で解放`)
   - 分は切り上げる(必要な滞在時間を短く見せないため。例: 61秒 → `2分以上滞在で解放`)
   - 0秒: `到達で解放`
   - 到達済みスポット: 解放条件の代わりに `到達済み`
3. **到達エリアの円**: `radiusMeters` の半径で薄い円を描く。見た目は滞在場所の設定画面(`StayPlaceEditorScreen` の `Circle`)と同じにする(`fillColor: ${theme.colors.primary}24`、`strokeColor: theme.colors.primary`、`strokeWidth: 1`)
4. **ラベルの見た目**: 地図タイルの上でも読めるよう、角丸の薄い座布団(半透明の背景)を敷いて文字を書く。ライト/ダークはテーマ値に追従する。文字は太字にしない
5. **表示の切り替え**: 全体を見渡している状態では、スポット名・解放条件・円をすべて非表示にする。拡大してしきい値を超えたらフェードインし、縮小してしきい値を下回ったらフェードアウトする
6. **行タップで寄る範囲**: そのスポットの到達エリアの円が、余白付きで完全に収まる範囲にする(円より狭く寄ると範囲の端が分からないため)。今の `createUserCenteredRegion`(固定 0.01°)は使わない
7. **表示しきい値**: 6 の寄る範囲に連動させる。行タップで寄ったときは必ず表示され、パック全体を見渡す範囲では表示されないこと

## 設計上の判断(実装者向け)

- **しきい値はスポットごとに判定する**。スポットごとに半径(150〜650m、スキーマ上は最大2000m)が違うため、一律の緯度差では「寄ったのに出ない」「全体表示なのに出る」が起きる。各スポットについて「見えている範囲の短辺(メートル)が、そのスポットの円の直径 × 寄るときの余白倍率 × 表示の許容倍率 以下」なら、そのスポットの詳細を表示する
  - 短辺を使う理由: 地図枠は横長(画面上1/3)で、ネイティブ地図は指定された region を枠のアスペクト比に合わせて広げて表示する。そのため、報告される region の短辺側が、寄るときに指定した範囲とほぼ一致する
  - 寄るときの余白倍率は 1.6 前後を目安にする(円の外側に余白があり、バッジ上下のラベルも枠内に収まる程度)。表示の許容倍率は 1.5 前後を目安にする(少し縮小しても消えない)。最終値は実装者が決めてよいが、定数として名前を付け、理由をJSDocに書く
- **寄る範囲の計算**: 緯度差 = 直径 × 余白倍率 ÷ 1度あたりのメートル数(約111,320m)。経度差は緯度に応じて cos(緯度) で割る。`src/utils/` 配下に既存の距離計算ユーティリティがあれば流用する
- **region の追跡**: `MapView` の `onRegionChangeComplete` で region を受け取り、各スポットの表示可否を求める。表示可否の集合が変わったときだけ state を更新し、地図操作のたびに無駄な再描画をしない。既存の `onRegionChangeComplete={() => setIsMapReady(true)}` の役割は残す
- **フェード**: `Animated` の opacity で 200〜250ms 程度。Android の `Marker` はカスタムビューをビットマップで撮るため、フェード中は `tracksViewChanges` を true にし、アニメーション完了後に false へ戻す(既存の「レイアウト完了で止める」仕組みと両立させる)
- **ラベルの配置**: 1つの `Marker` の中で [スポット名, バッジ, 解放条件] を縦に並べる。上下のラベル行は同じ高さ(1行固定)にして、バッジがマーカーの中心(=座標)に来るようにする。非表示時もレイアウトを変えない(opacity 0)か、アンカーがずれない別の方法を選ぶ
- **円のフェード**: `react-native-maps` の `Circle` は opacity を持たない。同じ Animated 値に合わせて fill/stroke の不透明度を段階的に変えるか、表示/非表示の切り替えで代替してよい。代替した場合はその理由をコメントに残す
- **文言**: 解放条件の文言を組み立てる処理は純粋関数として `src/features/landmarks/` に置く。`到達済み` などの定数は `src/ui/appText.ts` に置く
- **スタイル**: `src/ui/styles/achievementStyles.ts` に追加する(components 配下で `StyleSheet.create` は lint で禁止)。キー数を検証する `src/ui/__tests__/appStylesSplit.test.ts` の件数と内訳コメントも更新する

## タスク

### Task 1: 純粋関数

`src/features/landmarks/landmarkSpotMapDetails.ts`(名前は既存の命名に合わせて調整してよい)と、その `__tests__`:

- 解放条件の文言を返す関数(0秒 / 60分未満 / ちょうど60分 / 60分超 / 端数切り上げ / 不正値)
- スポットへ寄る region を返す関数(円の直径 × 余白倍率が短辺に収まる。高緯度では経度差が広がる)
- region とスポット半径から、詳細を表示するかを返す関数(寄る region ちょうどで表示 / 全体表示相当の広い region で非表示 / 許容倍率の境界)

### Task 2: スタイルと文言

- `achievementStyles.ts` に、ラベルの座布団・文字・ラベル列のスタイルを追加する
- `appText.ts` に `到達済み` などの定数を追加する
- `appStylesSplit.test.ts` の件数と内訳コメントを更新する

### Task 3: 地図への組み込み

`src/ui/components/LandmarkPackMapPreview.tsx` と `__tests__/LandmarkPackMapPreview.test.tsx`:

- 行タップのフォーカスで Task 1 の region を使う(既存テストの `createUserCenteredRegion` の期待値を置き換える)
- `onRegionChangeComplete` で表示可否を更新し、スポット名・解放条件・円を出し分ける
- テストで確認すること:
  - 初期表示(全体表示)ではスポット名・解放条件・円が出ない
  - 寄る region を `onRegionChangeComplete` で通知すると、そのスポットのスポット名・解放条件・円(半径 = `radiusMeters`)が出る
  - 到達済みスポットは `到達済み` になる
  - 再び広い region を通知すると消える(フェードアウト完了後に消える実装なら、タイマーを進めて確認する)
  - 行タップの `animateToRegion` が、円を収める region で呼ばれる
- テスト用の `react-native-maps` モックに `Circle` を追加する
